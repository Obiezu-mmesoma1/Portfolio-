The Problem:

Bike hub California is a bicycle parts distributor with resellers across the US. 
The Sales team received a messy reseller list with inconsistent formatting, extra spaces, and split data across columns, making it impossible to analyze or filter. 

Goal:

Clean and standardize the dataset so it's ready for reporting and analysis.

My Process
- TRIM: Removed leading and trailing spaces from text columns
  
- PROPER: Fixed inconsistent capitalization (e.g., "ALHAMBRA" → "Alhambra")
- 
- LEFT / RIGHT / MID: Extracted specific parts of text from combined columns
- Merged columns: Combined split data into single clean columns
- 
- Removed blanks & duplicates:Deleted empty rows and duplicate entries
- 
- Fixed spelling errors: Corrected misspelled reseller names

Result:
Transformed a messy, hard-to-analyze reseller list into a clean, standardized dataset. 

The data is now filterable, sortable, and ready for analysis.

Tools Used:

Microsoft Excel (TRIM, PROPER, LEFT, RIGHT, MID, Remove Duplicates, Merging Columns)
